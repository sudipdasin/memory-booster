# Edition boundary — public GPL Community versus any future private Pro

The MemBoost Pro Community source release from **v3.0.1** is under **GPL-3.0-or-later**. All repository source, GUI assets and compiled artifacts visible to visitors must be suitable for redistribution under the applicable licenses. Earlier versioned artifacts through v3.0.0 retain MIT grants; the inherited MIT license notice is preserved in `LICENSES/MIT-legacy.txt`.

Proprietary features must live in a separate private repository. Do **not** assume GPL-covered Community code can simply be linked into a closed-source derivative and redistributed as proprietary: GPL obligations may extend to a combined work. Only incorporate code with sufficient licenses/rights, obtain contributor permissions where necessary and consult appropriate licensing counsel prior to distributing a closed-source edition.

The owner controls the canonical GitHub repository, not independent compliant GPL forks. Use owner-reviewed pull requests, CODEOWNERS, and enforced branch rules for official contributions.
