# Public-source boundary

This repository is prepared for public access under MIT licensing. Anything committed here, including code, tests, screenshots and assets, becomes visible and redistributable to everyone once visibility is changed. Do not commit private credentials, private customer data, undisclosed proprietary modules or monetization-only features.

If a proprietary edition is desired in the future, develop its restricted code in a separate **private** repository and selectively sync the reviewed public foundation into that private repository. A license granted over a public release cannot be retroactively withdrawn from recipients who received it under MIT.
